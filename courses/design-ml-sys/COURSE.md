## Purpose

Personal study notes on Chip Huyen's *Designing Machine Learning Systems* (O'Reilly, First Edition, 2022), written to prepare for machine learning interviews. One Quarto chapter per **book chapter** plus a cumulative glossary. The goal is to learn each chapter well enough to answer interview questions on it comfortably and out loud, not to summarize the book page by page.

## Who these notes are for

The user already has a working background in machine learning (models, training, evaluation) but has not done ML interviews. Do not re-teach basics from zero; motivate briefly, then go to the distinctions, trade-offs, and failure modes an interviewer probes. Explain terms a strong ML practitioner might still stumble on when asked to define them precisely or to a non-technical listener.

## Source material

- Main source: `sources/Designing Machine Learning Systems.pdf` (Chip Huyen, O'Reilly, First Edition, May 2022; 11 chapters plus preface and epilogue).
- Target question style: `sources/example-ml-questions.md`. Notes and practice pages should leave the user able to answer questions like these (bias-variance diagnosis, metric choice under class imbalance, tree ensembles, interpretability to clinicians, statistics explained to non-technical stakeholders). Several examples are framed for biomedical or pharma settings; use that framing where the book's content supports it.
- Other files in `sources/` are context only. They do not get their own pages via `add`.

### Course-specific exceptions (override the skill's week defaults)

1. **Week = book chapter.** `/course-notes add design-ml-sys <N>` writes notes for **Chapter N** of the book. Filenames stay `lectures/weekNN.qmd` (the skill's convention), but chapter titles and prose say "Chapter N", never "Week N". The glossary groups terms under `## Chapter N`.
2. **One source, not one folder per week.** Read the chapter from the single book PDF in `sources/`. There is no `sources/weekN/` per week unless the user chooses to file extra context there. Per-chapter figures may still go in `lectures/figures/weekNN/`.
3. **Extra sources are context only.** Additional files dropped into `sources/` inform the notes for the matching chapter; they never become their own `add` page.
4. **`practice` = interview questions for one chapter.** `/course-notes practice design-ml-sys <N>` writes `lectures/weekNN-practice.qmd`: interview-style questions on Chapter N, modelled on `sources/example-ml-questions.md`, each with a collapsed worked answer. There is no homework, so there is no homework negative list.

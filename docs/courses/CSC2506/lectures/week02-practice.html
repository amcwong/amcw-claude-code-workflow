Week 2 practice: Decision theory and graphical models

Overview. These problems drill Week 2. Try each stem before opening the worked solution. The loss matrices, distributions, and graphs here are invented for practice; they are not the cancer-screening, regression, or Bayes-Ball examples from the lecture. Notation matches the week chapter. The exception is the final section, Tutorial questions, which restates the Week 2 tutorial’s own examples.

Problem 1: Two ways to be wrong

A helpdesk routes each incoming ticket either to an autoresponder (for routine questions) or to a human agent (for anything else). Two people disagree about how to design the router:

  • Person A wants to minimize the fraction of tickets sent to the wrong handler.
  • Person B points out that sending a genuinely urgent ticket to the autoresponder is much worse than sending a routine ticket to a human (wasted agent time, but no harm done), and wants the router to reflect that.

Which objective from the lecture, misclassification rate or expected loss, matches each person’s goal? Could the two objectives ever recommend the same decision rule?

TipWorked solution

This uses Week 2, From inference to decision and Misclassification rate.

Person A wants to minimize p(\text{mistake}), the plain count of wrong handler assignments from Misclassification rate: every error counts as one, regardless of which direction it runs. Person B wants a loss function (Week 2, Expected loss): a loss matrix that charges more for “urgent ticket sent to autoresponder” than for “routine ticket sent to a human,” and then minimizes the resulting expected loss.

The two objectives can agree. Misclassification rate is the special case of expected loss where the loss matrix has 0 on the diagonal and 1 everywhere off it, so if Person B’s matrix happened to be symmetric with equal off-diagonal costs, the discriminant rule would reduce to Person A’s rule exactly. They diverge only once the loss matrix is asymmetric, which is what Person B is actually asking for.

Answer. Person A: misclassification rate. Person B: expected loss with an asymmetric loss matrix. The two agree whenever the loss matrix has zero diagonal and equal off-diagonal costs (the 0/1 matrix or any positive multiple of it); a loss matrix is a strict generalization, not a different framework.

Problem 2: Inspecting a batch of widgets

A factory’s inspection station decides whether a widget is defective (\mathcal{C}_1) or good (\mathcal{C}_2). Passing a defective widget into a shipment costs 50 (recalls, refunds); scrapping a good widget costs 5 (wasted material). Correct calls cost 0.

For one widget, the classifier’s estimated posteriors are p(\mathcal{C}_1 \mid x) = 0.15 and p(\mathcal{C}_2 \mid x) = 0.85.

  1. Write the 2\times 2 loss matrix (rows: truth, columns: decision).
  2. Compute the discriminant rule’s two candidate costs and state its decision.
  3. Compare this to what the misclassification-rate rule (from Problem 1’s Person A) would decide.
TipWorked solution

This uses Week 2, Expected loss and The discriminant rule.

1. Loss matrix. L_{\text{defective},\text{scrap}} = 0, L_{\text{defective},\text{ship}} = 50, L_{\text{good},\text{scrap}} = 5, L_{\text{good},\text{ship}} = 0.

2. Discriminant rule. The rule assigns x to the decision j minimizing \sum_k L_{kj}\,p(\mathcal{C}_k\mid x):

\text{cost(ship)} = L_{\text{defective},\text{ship}}(0.15) + L_{\text{good},\text{ship}}(0.85) = 50(0.15) + 0(0.85) = 7.5, \text{cost(scrap)} = L_{\text{defective},\text{scrap}}(0.15) + L_{\text{good},\text{scrap}}(0.85) = 0(0.15) + 5(0.85) = 4.25.

Scrapping is cheaper, so the discriminant rule decides scrap, even though the widget is more likely good (0.85 > 0.15) than defective.

3. Comparison. The plain misclassification-rate rule from Misclassification rate only compares posteriors and would decide ship, since p(\mathcal{C}_2\mid x)=0.85 is the larger posterior. The rules disagree because the loss matrix charges 10 times more for shipping a defective widget than for scrapping a good one, so even a fairly low probability of defect is still worth acting on, exactly the same asymmetry that moved the lecture’s cancer-screening boundary.

Answer. Loss matrix as above; discriminant rule decides scrap (cost 4.25 vs. 7.5); the misclassification-rate rule would have decided ship.

Problem 3: A different conditional distribution

Fix an input x. Given that x, a continuous target t takes the values 1, 3, and 14, each with probability \tfrac13.

Compute \mathbb{E}[t\mid x]. Then compare the expected squared loss of the predictor y(x) = 8 against y(x) = \mathbb{E}[t\mid x], and confirm which one the lecture’s theorem says must be smaller.

TipWorked solution

This uses Week 2, Loss functions for regression.

Conditional mean: \mathbb{E}[t\mid x] = \tfrac13(1+3+14) = 6.

For y(x) = 8: \mathbb{E}[L] = \tfrac13\big[(8-1)^2+(8-3)^2+(8-14)^2\big] = \tfrac13(49+25+36) = \tfrac{110}{3} \approx 36.67.

For y(x) = \mathbb{E}[t\mid x] = 6: \mathbb{E}[L] = \tfrac13\big[(6-1)^2+(6-3)^2+(6-14)^2\big] = \tfrac13(25+9+64) = \tfrac{98}{3} \approx 32.67.

The conditional mean gives the smaller expected loss, matching the theorem: y(x) = \mathbb{E}[t\mid x] minimizes squared loss for any competing choice, not only y(x)=8. The decomposition behind this splits \mathbb{E}[L] into a piece that depends on y(x) (driven to zero exactly at the conditional mean) and a piece that does not (the irreducible noise), so no other constant can do better.

Answer. \mathbb{E}[t\mid x] = 6. Expected loss at y=8 is 110/3 \approx 36.67; at y=6 it is 98/3 \approx 32.67, confirming the conditional mean wins.

Problem 4: Counting parameters for five variables

Take N=5 binary variables x_1,\dots,x_5. Using the chain rule in the order x_1,\dots,x_5 with no assumptions, how many parameters does the factorization need?

Now suppose we are willing to assume x_5 depends only on x_2 and x_4 (not on x_1 or x_3), while every other factor stays as general as before. How many parameters does the factorization need now, and how many were saved?

TipWorked solution

This uses Week 2, Free parameters and the cost of the full joint and Why factor the joint.

With no assumptions, the chain rule gives p(x_1)p(x_2\mid x_1)p(x_3\mid x_1,x_2)p(x_4\mid x_1,x_2,x_3)p(x_5\mid x_1,x_2,x_3,x_4). Each factor p(x_j\mid x_1,\dots,x_{j-1}) needs 2^{j-1} parameters, so the totals are 1,2,4,8,16 for j=1,\dots,5, summing to 1+2+4+8+16=31, matching 2^5-1=31 exactly.

Replacing the last factor with p(x_5\mid x_2,x_4) shrinks its table from 2^4=16 parameters (one per configuration of four parents) to 2^2=4 (one per configuration of two parents). The new total is 1+2+4+8+4 = 19.

Savings: 31-19=12 parameters, all from dropping x_5’s dependence on x_1 and x_3. This is the same pattern as the lecture’s N=4 example: dropping dependence on conditioning variables shrinks that one factor’s table exponentially, and the saving compounds because that factor was the largest one in the sum.

Answer. No assumptions: 31 parameters. With x_5\mid x_2,x_4: 19 parameters. Savings: 12.

Problem 5: CPT sizes for an invented graph

Consider a DAG on five binary nodes y_1,\dots,y_5 with edges y_1 \to y_2, y_1 \to y_3, y_2 \to y_4, y_3 \to y_4, y_4 \to y_5 (so y_4 has two parents, y_2 and y_3).

For each node, state its parent count K_i and its CPT size 2^{K_i}. Sum these to get the total number of parameters, and compare to the 2^5-1 a fully-connected DAG on five nodes would need.

TipWorked solution

This uses Week 2, Directed graphical models.

Read the parent count off the incoming edges at each node:

  • y_1: no parents, K=0, CPT size 2^0=1.
  • y_2: one parent (y_1), K=1, CPT size 2^1=2.
  • y_3: one parent (y_1), K=1, CPT size 2.
  • y_4: two parents (y_2,y_3), K=2, CPT size 2^2=4.
  • y_5: one parent (y_4), K=1, CPT size 2.

Total: 1+2+2+4+2 = 11 parameters, against 2^5-1=31 for the fully-connected case on five nodes. The saving comes from every node having at most two parents instead of depending on every node before it; y_4’s CPT is the largest single piece because it is the only node with two parents.

Answer. K = (0,1,1,2,1), CPT sizes (1,2,2,4,2), total 11 parameters, versus 31 fully connected.

Problem 6: Chain, common cause, or collider?

Three sensors on a machine: a temperature reading (X), an internal wear level (Y), and a vibration reading (Z). Consider this causal story: high internal wear (Y) tends to raise both the temperature reading (X) and the vibration reading (Z), but the temperature and vibration sensors do not affect each other directly: X \leftarrow Y \rightarrow Z.

Which of the lecture’s three canonical structures is this? Are X and Z independent before observing Y? What happens once Y (the wear level) is observed?

TipWorked solution

This uses Week 2, Conditional independence: three canonical structures.

This is the common cause structure, X \leftarrow Y \rightarrow Z, with wear level Y as the shared cause of both readings.

Marginally (before observing Y), X and Z are dependent: a high temperature reading is evidence of high wear, which in turn makes a high vibration reading more likely, so the two readings move together even though neither sensor affects the other. This is the same “two effects of a shared cause are correlated” pattern as the lecture’s deadline example.

Once Y is observed, the joint factors as p(y)p(x\mid y)p(z\mid y), so p(x,z\mid y) = p(x\mid y)p(z\mid y): conditioning on the wear level uses up the shared explanation, and X \perp Z \mid Y. Knowing the wear level directly, the temperature reading tells us nothing more about the vibration reading.

Answer. Common cause. X and Z are marginally dependent, and become conditionally independent given Y: X \perp Z \mid Y.

Problem 7: Bayes Ball on a small graph

Consider a DAG with edges p \to q, r \to q, q \to s, r \to t (so q is a collider with parents p and r, and r also has a second child t).

  1. Is p \perp r \mid \emptyset (no conditioning set)?
  2. Is p \perp r \mid \{s\}?
  3. Is p \perp t \mid \{r\}?

For each, name the only path between the two nodes, identify the junction type(s) on it, and apply the Bayes Ball rules.

TipWorked solution

This uses Week 2, The Bayes Ball algorithm.

1. p \perp r \mid \emptyset. The only path between p and r is p \to q \leftarrow r. Here q is a collider. With C=\emptyset, neither q nor any descendant of q (that is, s) is in C, so the collider is blocked. The one path is blocked, so p \perp r \mid \emptyset.

2. p \perp r \mid \{s\}. Same path, p \to q \leftarrow r, same collider q. Now C=\{s\}, and s is a descendant of the collider q (via q \to s), so the collider is open: shading a descendant of a collider opens it, exactly the explaining-away rule. The path is active, so p \not\perp r \mid \{s\}. Conditioning on s, which is not even on the direct route between p and r, is what creates the dependency, the same pattern as the lecture’s c-shaded example.

3. p \perp t \mid \{r\}. The only path between p and t is p \to q \leftarrow r \to t. There are two junctions: q is a collider (parents p,r), and r is a fork on this path (edges r\to q and r\to t both point out of r). With C=\{r\}: at the fork r, r is shaded, so the fork is blocked. That already blocks the whole path regardless of q (checking anyway: at the collider q, neither q nor its descendant s is in C=\{r\}, so q is also blocked). So p \perp t \mid \{r\}.

Answer. (1) p\perp r\mid\emptyset: yes. (2) p\perp r\mid\{s\}: no. (3) p\perp t\mid\{r\}: yes.

Problem 8: Why does Naive Bayes save so many parameters?

A grocer wants to classify fruit as ripe (C=1) or unripe (C=0) from three binary features: color (X_1: red/green), softness (X_2: soft/firm), and smell (X_3: fragrant/faint). A Naive Bayes model assumes X_1, X_2, X_3 are conditionally independent given the ripeness label C.

Without computing any specific numbers, explain: (a) which of the lecture’s three canonical structures this independence assumption corresponds to, and why; (b) in general terms, why the assumption shrinks the parameter count from exponential in the number of features to linear in the number of features. (The exact MLE formulas for \hat\pi and \hat\theta_{jc} are left to work through with real counts on your own data; this problem is about the structural reason for the saving, not the computed values.)

TipWorked solution

This uses Week 2, Naive Bayes as a graphical model and Directed graphical models.

(a) Which structure. The assumption X_i \perp X_j \mid C for every feature pair is the common-cause structure repeated across every pair of features, with the ripeness label C playing the role of the shared cause. Each feature is an effect of C (color, softness, and smell are all downstream of whether the fruit is actually ripe), and once C is known, no feature carries extra information about any other feature. This is exactly the deadline example and Problem 6’s sensor example, generalized from one shared cause and two effects to one shared cause and d effects.

(b) Why the parameter count shrinks. Without any independence assumption, the DAG on C, X_1, X_2, X_3 is fully connected in the chain-rule order C,X_1,X_2,X_3: the i-th feature’s CPT conditions on C and every feature before it, so its table size doubles with each additional feature, giving a total that grows as 2^{d+1}-1 in the number of features d (Free parameters and the cost of the full joint, Why factor the joint). Removing every edge between features and keeping only the edges from C means each feature’s CPT now conditions on C alone, a table of fixed size regardless of how many other features exist. Summing a fixed-size table once per feature gives a total that grows linearly in d instead of exponentially. The structural reason is the same one from Directed graphical models: restricting how many parents a node can have is what buys the saving, and Naive Bayes pushes every feature’s parent set down to just \{C\}, the most aggressive restriction available short of assuming no dependence on C at all.

Answer. (a) Common cause, with C as the shared parent of every feature. (b) Fully connected costs grow exponentially in the number of features because each new feature’s CPT can condition on every earlier feature; capping every feature’s parent set at \{C\} makes each CPT a fixed size, so the total grows linearly instead.

Conditional independence drills

These problems drill conditional independence from both sides: checking it numerically from a table, and reading it off a graph. All setups are invented.

Problem 9: Independent given C, dependent without it

Three binary variables A,B,C have the joint distribution

(a,b,c) 001 011 101 111 000 010 100 110
p 0.03 0.07 0.12 0.28 0.36 0.04 0.09 0.01
  1. Check that A\perp B\mid C for C=1: is p(A{=}1,B{=}1\mid C{=}1)=p(A{=}1\mid C{=}1)\,p(B{=}1\mid C{=}1)? (The other entries and C=0 work the same way.)
  2. Are A and B independent marginally?
TipWorked solution

This uses the definition in Week 2, Conditional independence: three canonical structures, together with Week 1’s sum rule.

  1. First p(C{=}1)=0.03+0.07+0.12+0.28=0.5. Then p(A{=}1\mid C{=}1)=\frac{0.12+0.28}{0.5}=0.8, \qquad p(B{=}1\mid C{=}1)=\frac{0.07+0.28}{0.5}=0.7, p(A{=}1,B{=}1\mid C{=}1)=\frac{0.28}{0.5}=0.56=0.8\times0.7. The product rule holds. Doing the same for C=0 gives 0.02=0.2\times0.1, so A\perp B\mid C.

  2. Sum out C: p(A{=}1)=0.12+0.28+0.09+0.01=0.5, p(B{=}1)=0.07+0.28+0.04+0.01=0.4, and p(A{=}1,B{=}1)=0.28+0.01=0.29. Since 0.29\neq0.5\times0.4=0.20, A and B are dependent.

C is a common cause: it makes both A and B likely to be 1 together. Once C is known it explains everything they share, but if C is summed out, seeing A{=}1 hints that C{=}1, which makes B{=}1 more likely.

Answer. (1) Yes, 0.56=0.8\times0.7. (2) No: p(A{=}1,B{=}1)=0.29\neq0.20.

Problem 10: Why the three definitions agree

The week chapter gives three equivalent ways to say A\perp B\mid C. Show that p(a\mid b,c)=p(a\mid c) implies p(a,b\mid c)=p(a\mid c)\,p(b\mid c), and then show the reverse (assuming p(b\mid c)>0).

TipWorked solution

This proves the equivalence stated in the definition of Week 2, Conditional independence: three canonical structures. The only tool is the product rule with everything conditioned on c: p(a,b\mid c)=p(a\mid b,c)\,p(b\mid c).

Forward. Substitute p(a\mid b,c)=p(a\mid c) into the product rule: p(a,b\mid c)=p(a\mid c)\,p(b\mid c).

Reverse. Rearrange the product rule and substitute the factorization: p(a\mid b,c)=\frac{p(a,b\mid c)}{p(b\mid c)}=\frac{p(a\mid c)\,p(b\mid c)}{p(b\mid c)}=p(a\mid c).

The third form, p(b\mid a,c)=p(b\mid c), follows the same way with a and b swapped. All three say “once c is known, learning one of a,b tells us nothing more about the other”.

Answer. Both directions follow from p(a,b\mid c)=p(a\mid b,c)\,p(b\mid c).

Problem 11: Explaining away with two coins

Flip two independent fair coins, X and Z (1 for heads), and let Y=1 if at least one of them is heads, Y=0 otherwise. Compute p(Z{=}1), p(Z{=}1\mid Y{=}1), and p(Z{=}1\mid Y{=}1,X{=}1). What does this say about X and Z once Y is observed?

TipWorked solution

This is the explaining-away structure of Week 2, Conditional independence: three canonical structures, with Y a collider: X\to Y\leftarrow Z.

  • p(Z{=}1)=\frac12.
  • Y=1 in three of the four equally likely outcomes (HT,TH,HH), and Z=1 in two of them, so p(Z{=}1\mid Y{=}1)=\frac{2/4}{3/4}=\frac23.
  • If also X=1, then Y=1 is already guaranteed, so it carries no information about Z: p(Z{=}1\mid Y{=}1,X{=}1)=p(Z{=}1)=\frac12.

Given Y=1, learning X=1 moves our belief about Z from \frac23 down to \frac12: X=1 has “explained away” why Y=1. So X and Z, independent to begin with, are dependent once their common effect is observed.

Answer. \frac12, \frac23, \frac12: X\perp Z but X\not\perp Z\mid Y.

Problem 12: Which statements hold in a chain?

In the first-order chain X_1\to X_2\to X_3\to X_4, mark each statement as always true or not true in general:

  1. X_1\perp X_3\mid X_2
  2. X_1\perp X_4\mid X_2
  3. X_1\perp X_4\mid X_3
  4. X_1\perp X_3
  5. X_2\perp X_4\mid X_1
TipWorked solution

This uses the chain structure of Week 2, Conditional independence: three canonical structures and the blocking rule of Week 2, The Bayes Ball algorithm. There is only one path between any two nodes, and every interior node on it is a chain node, so a path is blocked exactly when some node strictly between the endpoints is observed.

  1. The path X_1\to X_2\to X_3 passes through the observed X_2: blocked. True.
  2. The path X_1\to X_2\to X_3\to X_4 passes through the observed X_2: blocked. True.
  3. The same path passes through the observed X_3: blocked. True.
  4. Nothing is observed, so the path is open. Not true in general.
  5. The path X_2\to X_3\to X_4 does not pass through X_1, so observing X_1 does not block it. Not true in general.

Answer. 1, 2, 3 true; 4 and 5 not true in general.

Problem 13: d-separation on a new graph

A DAG has edges u\to v, w\to v, v\to x, w\to y, y\to z. Decide each of the following:

  1. u\perp w
  2. u\perp w\mid x
  3. u\perp y\mid x
  4. u\perp z\mid\{x,y\}
TipWorked solution

This applies the d-separation definition of Week 2, The Bayes Ball algorithm. Every path from u must go u\to v\leftarrow w, so v is always a collider on it; its only descendant is x. From w the path can continue w\to y\to z, where w is a fork and y is a chain node.

  1. Path u\to v\leftarrow w. Neither v nor x is observed, so the collider blocks. Independent.
  2. Now x, a descendant of v, is observed, so the collider is open. The path is active: not independent.
  3. Path u\to v\leftarrow w\to y. The collider v is open (via x), and the fork w is unobserved, so it is open too. Active: not independent.
  4. Path u\to v\leftarrow w\to y\to z. The collider is open, but the chain node y is observed, which blocks it. This is the only path, so independent.

Answer. (1) Yes. (2) No. (3) No. (4) Yes.

Tutorial questions

The questions below are the Week 2 tutorial’s examples, restated as questions. They use the tutorial’s own graphs and models, so several are also worked in the week chapter; each solution says where.

Tutorial question 1: Factorize the Bayes Ball graph

A DAG has five nodes with edges a\to e, f\to e, e\to c, and f\to b (the graph of Week 2, Figure 3). Ignoring any observed nodes, what factorization of p(a,b,c,e,f) does it imply?

TipWorked solution

This uses Week 2, Directed graphical models: one factor per node, conditioned on that node’s parents. a and f have no parents, e has parents a and f, c has parent e, and b has parent f.

Answer. p(a,b,c,e,f)=p(a)\,p(f)\,p(e\mid a,f)\,p(c\mid e)\,p(b\mid f).

Tutorial question 2: Is a independent of b?

On the same graph, use Bayes Ball to decide whether a\perp b:

  1. conditioned on c;
  2. conditioned on f.
TipWorked solution

This is the tutorial example worked in Week 2, The Bayes Ball algorithm.

The only path from a to b is a\to e\leftarrow f\to b. It has two interior nodes: e, where the arrows meet head-to-head, and f, where they meet tail-to-tail.

  1. Conditioning on c: e is a collider that is not observed, but its descendant c is, so rule (b) does not block it. f is tail-to-tail and not observed, so rule (a) does not block it either. The path is open.

  2. Conditioning on f: f is tail-to-tail and observed, which blocks the path by rule (a). (e is also blocking, since neither it nor its descendant c is observed.)

Answer. (a) No, a\not\perp b\mid c. (b) Yes, a\perp b\mid f.

Tutorial question 3: The general spam model

A text is classified as spam (C=1) or not (C=0) from a bag-of-words vector X=(X_1,\dots,X_d), where X_i\in\{0,1\} records whether dictionary word i appears. Without any independence assumptions, factorize p(C,X) with the chain rule in the order C,X_1,\dots,X_d. Draw the corresponding DAG in your head: how many edges enter X_i, and how many parameters does the whole model need?

TipWorked solution

This uses Week 2, Free parameters and the cost of the full joint and Week 2, Naive Bayes as a graphical model.

The chain rule gives p(C,X)=p(C)\,p(X_1\mid C)\prod_{i=2}^dp(X_i\mid X_1,\dots,X_{i-1},C). Each factor conditions on everything to its left, so the DAG has an edge into each node from every earlier node. The graph on d+1 nodes is fully connected.

Node X_i has i parents (C and X_1,\dots,X_{i-1}), all binary, so its table has 2^i rows, each needing one number. C needs 1 number. The total is 1+\sum_{i=1}^d2^i=1+(2^{d+1}-2)=2^{d+1}-1, the same as specifying the full joint table over d+1 binary variables. This factorization assumes nothing, so it saves nothing.

Answer. X_i has i incoming edges; the model needs 2^{d+1}-1 parameters.

Tutorial question 4: Naive Bayes

Now remove every edge between the X_i’s and keep only the edges from C. What factorization does this imply, what independence does it assume, and how many parameters does it need?

TipWorked solution

This is Week 2, Naive Bayes as a graphical model.

Each X_i now has the single parent C, so p(C,X)=p(C)\prod_{i=1}^dp(X_i\mid C). The assumption is p(X_i\mid X_1,\dots,X_{i-1},C)=p(X_i\mid C): every word is independent of every other word given the class. C needs 1 parameter and each X_i needs 2 (one for each value of C).

Answer. p(C)\prod_ip(X_i\mid C), with 1+2d parameters: linear in d instead of exponential.

Tutorial question 5: Learning Naive Bayes by maximum likelihood

Parameterize the Naive Bayes model by p(C=1)=\pi and p(X_j=1\mid C=c)=\theta_{jc}. Given N labelled texts (x^{(i)},c^{(i)}), write the log-likelihood as a sum of Bernoulli log-likelihoods and find the MLEs of \pi and \theta_{jc}.

TipWorked solution

This reteaches Week 2, Naive Bayes as a graphical model using the Bernoulli MLE of Week 1, Maximum likelihood estimation.

Split the log-likelihood. The factorization turns the log of each example’s probability into a sum: \ell(\theta)=\sum_{i=1}^N\log p(c^{(i)})+\sum_{j=1}^d\sum_{i=1}^N\log p\big(x_j^{(i)}\mid c^{(i)}\big). The first sum involves only \pi; the j-th inner sum involves only \theta_{j0} and \theta_{j1}. Each piece can be maximized separately.

The labels. p(c^{(i)})=\pi^{c^{(i)}}(1-\pi)^{1-c^{(i)}}, so the first sum is \sum_ic^{(i)}\log\pi+\sum_i(1-c^{(i)})\log(1-\pi), a Bernoulli log-likelihood.

The features. p(x_j^{(i)}\mid c)=\theta_{jc}^{x_j^{(i)}}(1-\theta_{jc})^{1-x_j^{(i)}}. Splitting the examples by label, the j-th sum is a Bernoulli log-likelihood for \theta_{j1} over the spam texts plus one for \theta_{j0} over the others.

Set derivatives to zero. Each Bernoulli MLE is a fraction of ones: \hat\pi=\frac{\sum_i\mathbb{1}[c^{(i)}=1]}{N}, \qquad \hat\theta_{jc}=\frac{\sum_i\mathbb{1}[x_j^{(i)}=1,\ c^{(i)}=c]}{\sum_i\mathbb{1}[c^{(i)}=c]}.

Answer. \hat\pi is the fraction of texts that are spam; \hat\theta_{j1} is the fraction of spam texts containing word j (and \hat\theta_{j0} the same among non-spam texts).

Tutorial question 6: A second-order Markov chain

The order of a Markov chain is the number of previous states the current state may depend on. Write the factorization of p(x_{1:T}) for a first-order chain and for a second-order chain. Which edges does the second-order DAG add?

TipWorked solution

This expands the Markov-chain bullet of Week 2, DGMs in the wild. Week 5 develops Markov chains in full.

First order, each state depends on the one before: p(x_{1:T})=p(x_1)\prod_{t=2}^Tp(x_t\mid x_{t-1}). Second order, each state depends on the two before: p(x_{1:T})=p(x_1,x_2)\prod_{t=3}^Tp(x_t\mid x_{t-1},x_{t-2}). The first two states have no two predecessors, so they share the opening factor p(x_1,x_2).

Answer. The second-order DAG keeps the edges x_{t-1}\to x_t and adds a skip edge x_{t-2}\to x_t into every node from x_3 on.

Tutorial question 7: Hidden Markov models

In a hidden Markov model, hidden states Z_t (each taking one of K values) form a first-order Markov chain, and each Z_t emits an observation X_t. Write the factorization of p(X_{1:T},Z_{1:T}).

TipWorked solution

This is the HMM bullet of Week 2, DGMs in the wild. Write the joint as p(Z_{1:T})\,p(X_{1:T}\mid Z_{1:T}). The first factor is a first-order chain. In the second, each X_t has the single parent Z_t.

Answer. p(X_{1:T},Z_{1:T})=p(Z_1)\prod_{t=2}^Tp(Z_t\mid Z_{t-1})\prod_{t=1}^Tp(X_t\mid Z_t).

Tutorial question 8: The noisy-OR model

The Quick Medical Reference network has binary hidden disease nodes h=\{h_s\} and binary visible symptom nodes v=\{v_t\}, with edges only from diseases to symptoms. Its symptom model is a noisy-OR: p(v_t=0\mid h)=\prod_{s\in\mathrm{pa}(t)}\theta_{st}^{\mathbb{1}(h_s=1)}, \qquad \theta_{st}=p(v_t=0\mid h_s=1,\ \text{all other parents }0).

  1. Write the joint p(v,h) and give p(v_t=1\mid h).
  2. Without any extra node, what is p(v_t=1\mid h) for a patient with none of the listed diseases? Why does the model add a dummy disease h_0 that is always 1?
TipWorked solution

This expands the medical-diagnosis bullet of Week 2, DGMs in the wild.

  1. Diseases have no parents and each symptom’s parents are diseases, so p(v,h)=\prod_sp(h_s)\prod_tp\big(v_t\mid h_{\mathrm{pa}(t)}\big), \qquad p(v_t=1\mid h)=1-\prod_{s\in\mathrm{pa}(t)}\theta_{st}^{\mathbb{1}(h_s=1)}. The tutorial’s reading: flip one coin per active parent disease, with heads probability \theta_{st}. The symptom is absent only if every coin comes up heads.

  2. With no active disease every exponent is 0, the product is 1, and p(v_t=1\mid h)=0: such a patient could never show any symptom, so observing a symptom with no listed cause would get probability zero. The dummy node h_0=1 stands for all unknown diseases. It is always active, so it contributes a factor \theta_{0t} to every product.

Answer. (1) p(v_t=1\mid h)=1-\prod_{s}\theta_{st}^{\mathbb{1}(h_s=1)}. (2) Zero without the dummy node; with it, 1-\theta_{0t}>0.

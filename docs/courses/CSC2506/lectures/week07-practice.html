General math

Gaussian density (one dimension)

\mathcal N(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)

  • Moments: if z\sim\mathcal N(\mu,\sigma^2) then \mathbb E[z]=\mu, \mathbb E[(z-\mu)^2]=\sigma^2, and \mathbb E[z^2]=\mu^2+\sigma^2.
  • Standard normal noise: \epsilon\sim\mathcal N(0,1) has \mathbb E[\epsilon]=0 and \mathbb E[\epsilon^2]=1.
  • Shift and scale: \mu+\sigma\epsilon\sim\mathcal N(\mu,\sigma^2).
  • Tail values for Z\sim\mathcal N(0,1): P(|Z|\le1)\approx0.683, P(|Z|\le1.5)\approx0.866, P(|Z|\le2)\approx0.954.

Calculus and logs

  • Chain rule: \frac{d}{d\phi}f(T(\phi))=f'(T(\phi))\,T'(\phi).
  • Sigmoid: \sigma(a)=\frac{1}{1+e^{-a}}\in(0,1), so a sigmoid output is a valid probability.
  • Log rules: \log(ab)=\log a+\log b, \log\frac ab=\log a-\log b, \log e^a=a.
  • Values for working by hand: \ln2\approx0.693, \ln3\approx1.099, \ln5\approx1.609, \ln10\approx2.303, e^{-1}\approx0.368, e^{-1/2}\approx0.607, e^{-2}\approx0.135, e^{1/4}\approx1.284, e\approx2.718, \frac{1}{\sqrt{2\pi}}\approx0.399.

The ELBO (The ELBO: evidence lower bound, Two formulations of the ELBO)

Evidence lower bound

\mathcal L(\phi)=\mathbb E_{z\sim q_\phi}\big[\log p(x,z)-\log q_\phi(z)\big]

The identity behind the bound

\mathcal L(\phi)+\mathrm{KL}\big(q_\phi(z)\,\|\,p(z\mid x)\big)=\log p(x)

First form: expected log-joint plus entropy

\mathcal L(\phi)=\mathbb E_{q_\phi}\big[\log p(x,z)\big]+H(q_\phi), \qquad H(q)=-\mathbb E_q[\log q(z)]

Second form: expected log-likelihood minus KL to the prior

\mathcal L(\phi)=\mathbb E_{q_\phi}\big[\log p(x\mid z)\big]-\mathrm{KL}\big(q_\phi(z)\,\|\,p(z)\big)

  • Symbols: x is the observed data, z the latent variable, q_\phi the variational distribution with parameters \phi, and p(z\mid x)=p(x,z)/p(x) the posterior.
  • KL divergence: \mathrm{KL}(q\,\|\,p)=\sum_z q(z)\log\frac{q(z)}{p(z)} (an integral for continuous z). It is \ge0, and 0 only when q=p.
  • Why it is a lower bound: KL \ge0, so \mathcal L\le\log p(x). The sum is fixed by the model, so raising \mathcal L lowers the KL gap by exactly the same amount.
  • Jensen’s inequality route: \log\mathbb E_q\!\left[\frac{p(x,z)}{q(z)}\right]\ge\mathbb E_q\!\left[\log\frac{p(x,z)}{q(z)}\right], and the left side is \log p(x). Equality holds exactly when the ratio p(x,z)/q(z) is constant in z, that is, when q is the posterior.

Gradients and the reparameterization trick (Maximizing the ELBO: gradients of an expectation, The reparameterization trick)

What we are doing: a plain draw from q_\phi gives a number with no formula linking it to \mu and \sigma, so there is nothing to differentiate. If instead we draw \epsilon from a fixed p_0 and set z=T(\epsilon,\phi), then for each fixed \epsilon the sample z is a differentiable function of \phi, and we can differentiate with respect to \phi.

Gradient ascent on the ELBO

\phi_{t+1}=\phi_t+s_t\,\nabla_\phi\mathcal L(\phi_t)

The naive swap fails when the sampling distribution depends on \phi

\nabla_\phi\,\mathbb E_{z\sim q_\phi}\big[f(z)\big]\ \ne\ \mathbb E_{z\sim q_\phi}\big[\nabla_\phi f(z)\big]

Reparameterization

\epsilon\sim p_0(\epsilon),\qquad z=T(\epsilon,\phi)\ \sim\ q_\phi(z)

\nabla_\phi\,\mathbb E_{z\sim q_\phi}\big[f(z)\big]=\mathbb E_{\epsilon\sim p_0}\big[\nabla_\phi f(T(\epsilon,\phi))\big]

  • When the swap is allowed: when the distribution we average over does not depend on \phi. Reparameterization creates that situation by moving all the randomness into \epsilon.
  • Gaussian: z=\mu+\sigma\epsilon, \epsilon\sim\mathcal N(0,1), so \frac{\partial z}{\partial\mu}=1 and \frac{\partial z}{\partial\sigma}=\epsilon.
  • Location-scale families (shift and stretch a fixed distribution) all work the same way, for example a uniform: z=a+(b-a)u with u\sim\mathrm{Uniform}(0,1).
  • Inverse CDF: if F is a continuous distribution function and u\sim\mathrm{Uniform}(0,1), then z=F^{-1}(u) has distribution F. It is a valid T when F^{-1} is differentiable in the parameters.
  • No differentiable T exists for a discrete q_\phi (Problem 6).

Stochastic variational inference (Stochastic variational inference)

SVI gradient estimate from m noise samples

\nabla_\phi\mathcal L(\phi)\approx\frac1m\sum_{i=1}^m\nabla_\phi\Big[\log p\big(x,T(\phi,\epsilon_i)\big)-\log q_\phi\big(T(\phi,\epsilon_i)\big)\Big]

  • Each term is the exact gradient for one fixed draw \epsilon_i. The average is unbiased, and its standard deviation shrinks like 1/\sqrt m.
  • MCMC vs SVI: MCMC is exact in the limit, handles multimodal posteriors, but is slow. SVI is fast and scales to large data, but is only as good as its family, and the reverse KL is mode-seeking.

Autoencoders (A prerequisite: principal component analysis, A 2-layer autoencoder, Issues with deterministic autoencoders)

Two-layer autoencoder and its reconstruction error

y_k(x,w)=\sum_{j=1}^M w^{(2)}_{kj}\,\sigma\Big(\sum_{i=1}^D w^{(1)}_{ji}x_i\Big),\qquad E(w)=\frac12\sum_{n=1}^N\big\|y(x_n,w)-x_n\big\|^2

  • Symbols: D inputs and outputs, M<D bottleneck units, first-layer weights w^{(1)} (M\times D), second-layer weights w^{(2)} (D\times M), activation \sigma (not a standard deviation here).
  • PCA: for centred data, the first M principal components are the top M eigenvectors of the covariance \frac1N\sum_n x_nx_n^\top. Projecting onto them leaves a total squared error of N times the sum of the discarded eigenvalues, the smallest possible for any M-dimensional subspace.
  • Linear autoencoder: with identity activations its M hidden units span the PCA subspace, so it can do no better than PCA.
  • Pixel-wise error: \sum_d(\tilde x_d-x_d)^2 compares pixels in the same position only.

Variational autoencoders (Variational autoencoders, Tutorial: the VAE as a latent variable model)

The VAE loss for one image (negative ELBO, one sample)

\ell=\mathrm{BCE}(\mathbf p,x)+\beta\cdot\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,\mathcal N(0,I)\big),\qquad\mathbf p=f(z^*,\theta)

Reparameterized sample

z^*=\mu+\sigma\odot\epsilon^*,\qquad\sigma=\exp\big(\tfrac12\log\sigma^2\big),\qquad\epsilon^*\sim\mathcal N(0,I)

Binary cross-entropy

\mathrm{BCE}(\mathbf p,x)=-\sum_{d=1}^D\big[x_d\log p_d+(1-x_d)\log(1-p_d)\big]

Closed-form KL to the standard normal prior

\mathrm{KL}=\frac12\sum_{m=1}^M\Big(\sigma_m^2+\mu_m^2-1-\log\sigma_m^2\Big)

  • Symbols: the encoder outputs \mu=g_\mu(x,\phi) and \log\sigma^2=g_{\log\sigma^2}(x,\phi), one entry per latent dimension m=1,\dots,M. The decoder outputs pixel probabilities \mathbf p\in(0,1)^D. \odot is elementwise multiplication. \beta=1 gives exactly the negative ELBO.
  • One dimension of the KL: \frac12(\sigma^2+\mu^2-1-\log\sigma^2), zero only at \mu=0, \sigma^2=1.
  • Mixture of Gaussians: p(x)=\sum_k\lambda_k\,\mathcal N(x;\mu_k,\sigma_k^2), and by Bayes’ rule p(z=k\mid x)=\dfrac{\lambda_k\,\mathcal N(x;\mu_k,\sigma_k^2)}{p(x)}.
  • Amortized vs per-point parameters: with N data points and M latent dimensions, private \phi_i=(\mu_i,\log\sigma_i^2) cost 2MN numbers. An amortized encoder has a fixed count that does not grow with N.

The notebook (Code walk-through: the VAE notebook)

  • Convolution output size: \lfloor(n+2\cdot\text{padding}-\text{kernel})/\text{stride}\rfloor+1. With kernel 4, stride 2, padding 1 this halves n.
  • Transposed convolution output size: (n-1)\cdot\text{stride}-2\cdot\text{padding}+\text{kernel}. With the same settings this doubles n.
  • Parameter counts: a (transposed) convolution with C_\text{in} input channels, C_\text{out} output channels and a 4\times4 kernel has 16\,C_\text{in}C_\text{out}+C_\text{out} parameters. A linear layer from a to b features has ab+b.
  • The notebook’s loss: BCE with reduction='sum' (over pixels and images) plus variational_beta times the KL summed over latent dimensions and images.

The ELBO and its two forms

Problem 1: Which of the three quantities can we compute?

We have a latent variable model in which we can evaluate the prior p(z) and the likelihood p(x\mid z) for any z, so we can evaluate the joint p(x,z). We have chosen a variational family q_\phi(z) that we can sample from and whose density we can evaluate.

  1. For each of \log p(x), \mathrm{KL}(q_\phi(z)\,\|\,p(z\mid x)) and \mathcal L(\phi), say whether we can compute it (exactly, or by averaging over samples from q_\phi), and why.
  2. A colleague says: “We cannot measure how close q_\phi is to the posterior, so we cannot improve it.” Use the identity on the aid sheet to explain what is wrong with this argument.
TipWorked solution

This uses Week 7, The ELBO and Why “evidence lower bound”?.

Part 1.

  • \log p(x)=\log\int p(x,z)\,dz needs the integral over every z. For the models this week (a neural-network decoder), that integral has no closed form, so we cannot compute it.
  • The KL divergence to the posterior needs p(z\mid x)=p(x,z)/p(x), whose denominator is the same intractable p(x). So we cannot compute it either.
  • \mathcal L(\phi)=\mathbb E_{q_\phi}[\log p(x,z)-\log q_\phi(z)] needs only the joint and q_\phi, both of which we can evaluate. The expectation may not have a closed form, but we can estimate it by drawing z from q_\phi and averaging. So we can compute it, at least approximately.

Part 2. The identity says \mathcal L(\phi)+\mathrm{KL}(q_\phi\,\|\,p(z\mid x))=\log p(x), and the right side does not depend on \phi. Any change of \phi that raises \mathcal L by some amount lowers the KL by exactly that amount. We never see the KL itself, but we do not need to: improving the quantity we can compute is the same as improving the one we cannot.

Answer: only \mathcal L(\phi) is computable; raising it lowers the KL gap one-for-one, so maximizing the ELBO improves q_\phi without ever measuring the gap.

Problem 2: Comparing two approximations by their ELBO

Use Model T. Two candidate approximations are proposed:

q_A=(0.6,\ 0.3,\ 0.1), \qquad q_B=\left(\tfrac13,\ \tfrac13,\ \tfrac13\right).

  1. Compute \mathcal L for each, using only the joint p(x,z). Which approximation does the ELBO prefer?
  2. Now compute p(x), the posterior p(z\mid x), and the KL gap of each candidate. Confirm that \mathcal L+\mathrm{KL}=\log p(x) for both, and that the ELBO’s preference matches the smaller gap.
TipWorked solution

This uses Week 7, The ELBO.

Part 1. For a discrete z the expectation is a sum, \mathcal L=\sum_z q(z)\big[\log p(x,z)-\log q(z)\big]. The logs of the joint are \log0.10\approx-2.303, \log0.06\approx-2.813, \log0.04\approx-3.219.

  • q_A: the three terms are 0.6(-2.303+0.511), 0.3(-2.813+1.204) and 0.1(-3.219+2.303), that is -1.075, -0.483, -0.092. So \mathcal L(q_A)\approx-1.650.
  • q_B: \log\tfrac13\approx-1.099, so the terms are \tfrac13(-2.303+1.099), \tfrac13(-2.813+1.099), \tfrac13(-3.219+1.099), that is -0.401, -0.572, -0.707. So \mathcal L(q_B)\approx-1.680.

q_A has the larger ELBO, so the ELBO prefers q_A. We reached this without knowing p(x).

Part 2. Summing the joint, p(x)=0.10+0.06+0.04=0.20, so \log p(x)=\log0.2\approx-1.609. The posterior is the joint divided by p(x): p(z\mid x)=(0.5,\ 0.3,\ 0.2).

  • q_A: \mathrm{KL}=0.6\log\frac{0.6}{0.5}+0.3\log\frac{0.3}{0.3}+0.1\log\frac{0.1}{0.2}=0.109+0-0.069\approx0.040.
  • q_B: \mathrm{KL}=\tfrac13\big(\log\tfrac{1/3}{0.5}+\log\tfrac{1/3}{0.3}+\log\tfrac{1/3}{0.2}\big)=\tfrac13(-0.405+0.105+0.511)\approx0.070.

Check: -1.650+0.040=-1.610 and -1.680+0.070=-1.610, both equal to \log p(x)\approx-1.609 up to rounding.

Answer: \mathcal L(q_A)\approx-1.650>\mathcal L(q_B)\approx-1.680, so the ELBO prefers q_A, and indeed q_A has the smaller gap (0.040 against 0.070 nats).

Problem 3: The same ELBO, split two ways

Use Model T and q_A=(0.6,\ 0.3,\ 0.1) from Problem 2.

  1. Compute the first form: the expected log-joint \mathbb E_{q_A}[\log p(x,z)] and the entropy H(q_A).
  2. Compute the second form: the expected log-likelihood \mathbb E_{q_A}[\log p(x\mid z)] and \mathrm{KL}(q_A\,\|\,p(z)) to the prior.
  3. Check that both give the value of \mathcal L(q_A) from Problem 2, and say in one sentence what each term of the second form rewards.
TipWorked solution

This uses Week 7, Two formulations of the ELBO.

Part 1. The expected log-joint is 0.6(-2.303)+0.3(-2.813)+0.1(-3.219)=-1.382-0.844-0.322\approx-2.547. The entropy is -\big[0.6(-0.511)+0.3(-1.204)+0.1(-2.303)\big]=0.307+0.361+0.230\approx0.898. Their sum is -2.547+0.898=-1.649.

Part 2. The likelihoods are (0.25,\ 0.15,\ 0.20), with logs -1.386, -1.897, -1.609. The expected log-likelihood is 0.6(-1.386)+0.3(-1.897)+0.1(-1.609)=-0.832-0.569-0.161\approx-1.562. The KL to the prior (0.4,\ 0.4,\ 0.2) is 0.6\log\tfrac{0.6}{0.4}+0.3\log\tfrac{0.3}{0.4}+0.1\log\tfrac{0.1}{0.2}=0.243-0.086-0.069\approx0.088. The second form gives -1.562-0.088=-1.650.

Part 3. Both agree with \mathcal L(q_A)\approx-1.650 from Problem 2 (the last digit differs only by rounding). The split works because \log p(x,z)=\log p(x\mid z)+\log p(z): the prior’s part of the log-joint and the entropy combine into minus the KL to the prior. In the second form, the expected log-likelihood rewards putting q’s mass on values of z that explain x well (here z=1, with the largest likelihood 0.25), and the KL term penalizes moving q away from the prior.

Answer: first form -2.547+0.898, second form -1.562-0.088, both \approx-1.650.

Gradients of an expectation and the reparameterization trick

Problem 4: The naive swap, with a parameter in the spread

Let z\sim\mathcal N(\mu,\sigma^2) with parameters \phi=(\mu,\sigma), and take f(z)=(z-c)^2 for a fixed constant c.

  1. Compute \mathbb E[f(z)] as a function of \mu, \sigma and c, and from it the true gradients \partial/\partial\mu and \partial/\partial\sigma.
  2. Compute what the naive swap \mathbb E[\nabla_\phi f(z)] gives for each.
  3. Evaluate both at \mu=1, \sigma=2, c=3, and explain in words why the true \sigma-gradient is positive.
TipWorked solution

This uses Week 7, Maximizing the ELBO: gradients of an expectation.

Part 1. Expand around the mean: z-c=(z-\mu)+(\mu-c), so \mathbb E[(z-c)^2]=\mathbb E[(z-\mu)^2]+2(\mu-c)\,\mathbb E[z-\mu]+(\mu-c)^2=\sigma^2+(\mu-c)^2, since \mathbb E[z-\mu]=0. Differentiating, \frac{\partial}{\partial\mu}=2(\mu-c) and \frac{\partial}{\partial\sigma}=2\sigma.

Part 2. f(z)=(z-c)^2 contains neither \mu nor \sigma, so \nabla_\phi f(z)=0 for every z and the naive swap gives 0 for both. All the dependence on \phi is in which z values are likely, which the swap ignores.

Part 3. At \mu=1, \sigma=2, c=3: the true gradients are 2(1-3)=-4 and 2\cdot2=4; the naive swap gives 0 and 0. The \sigma-gradient is positive because a wider distribution puts more mass far from c on both sides, and f grows with the distance from c, so the average of f grows with \sigma.

Answer: true gradients (2(\mu-c),\ 2\sigma)=(-4,\ 4); naive swap (0,\ 0).

Problem 5: Recovering both gradients by reparameterizing

Continue Problem 4. Write z=\mu+\sigma\epsilon with \epsilon\sim\mathcal N(0,1).

  1. Write f as a function of \epsilon, \mu and \sigma, and differentiate it with respect to \mu and with respect to \sigma for a fixed \epsilon.
  2. Take the expectation over \epsilon of each derivative and check that you recover the true gradients from Problem 4.
TipWorked solution

This uses Week 7, The reparameterization trick.

Part 1. f(\mu+\sigma\epsilon)=(\mu+\sigma\epsilon-c)^2. By the chain rule, with \partial z/\partial\mu=1 and \partial z/\partial\sigma=\epsilon, \frac{\partial f}{\partial\mu}=2(\mu+\sigma\epsilon-c),\qquad\frac{\partial f}{\partial\sigma}=2(\mu+\sigma\epsilon-c)\,\epsilon. Now \mu and \sigma appear inside the function, so the derivative sees them.

Part 2. The distribution of \epsilon does not depend on \phi, so the gradient may move inside the expectation. Using \mathbb E[\epsilon]=0 and \mathbb E[\epsilon^2]=1: \mathbb E\big[2(\mu+\sigma\epsilon-c)\big]=2(\mu-c),\qquad\mathbb E\big[2(\mu-c)\epsilon+2\sigma\epsilon^2\big]=0+2\sigma=2\sigma. Both match Problem 4. The \sigma-gradient is new compared with the week’s example: it arrives through the factor \epsilon in \partial z/\partial\sigma, and only the \epsilon^2 part survives the average.

Answer: \mathbb E_\epsilon[\partial f/\partial\mu]=2(\mu-c) and \mathbb E_\epsilon[\partial f/\partial\sigma]=2\sigma, the true gradients.

Problem 6: Which distributions can be reparameterized?

For each family, either give a differentiable T(u,\phi) with u\sim\mathrm{Uniform}(0,1) that produces it, or explain why no such T exists.

  1. z\sim\mathrm{Uniform}(a,b), with parameters \phi=(a,b).
  2. z\sim\mathrm{Exponential}(\lambda), with density \lambda e^{-\lambda z} for z\ge0, so P(z>t)=e^{-\lambda t}. (Hint: use the inverse CDF on the aid sheet.)
  3. z\sim\mathrm{Bernoulli}(\theta).
TipWorked solution

This uses Week 7, The reparameterization trick, which says the trick works “in some situations” and needs a differentiable T.

Part 1. Shift and stretch the unit interval: z=a+(b-a)u. When u is uniform on [0,1], z is uniform on [a,b]. The derivatives \partial z/\partial a=1-u and \partial z/\partial b=u exist everywhere. This is a location-scale family, like the Gaussian.

Part 2. This is inverse transform sampling. The CDF of the exponential distribution is F(t)=1-e^{-\lambda t}. One convenient choice is z=-\frac{\ln u}{\lambda}, which uses 1-u in place of u (both are uniform). Check: P(z>t)=P(-\ln u>\lambda t)=P(u<e^{-\lambda t})=e^{-\lambda t}, which is right. The derivative \partial z/\partial\lambda=\frac{\ln u}{\lambda^2} exists for every u\in(0,1).

Part 3. Any way of producing a Bernoulli from u has the form z=\mathbb 1[u<\theta] (or something equivalent): z is 1 when u falls below \theta, else 0. As a function of \theta this is a step. Its derivative is 0 everywhere except at the jump, where it does not exist. So \nabla_\theta f(T(u,\theta)) is 0 almost surely, and its average is 0, even though \mathbb E[f(z)]=\theta f(1)+(1-\theta)f(0) clearly changes with \theta. We are back to the failure of Problem 4. In general, a discrete z can only jump between values, so no differentiable T exists.

Answer: uniform: z=a+(b-a)u; exponential: z=-\ln(u)/\lambda; Bernoulli: no differentiable T, because z must jump between 0 and 1.

Problem 7: When may the gradient move inside?

For each gradient, say whether \nabla_\phi\mathbb E[\cdot]=\mathbb E[\nabla_\phi\,\cdot\,] holds as written, and check by computing both sides.

  1. \nabla_\phi\,\mathbb E_{z\sim\mathcal N(0,1)}\big[(\phi z+1)^2\big].
  2. \nabla_\phi\,\mathbb E_{z\sim\mathcal N(\phi,1)}\big[z\big].
  3. The gradient of an average loss over a fixed training set x_1,\dots,x_N, \nabla_\phi\frac1N\sum_{n=1}^N\ell(x_n,\phi), estimated from a random mini-batch.
TipWorked solution

This uses the “easy case” and “our case” of Week 7, gradients of an expectation.

Part 1. Allowed. The distribution \mathcal N(0,1) does not involve \phi. True side: \mathbb E[(\phi z+1)^2]=\phi^2\mathbb E[z^2]+2\phi\,\mathbb E[z]+1=\phi^2+1, with gradient 2\phi. Swapped side: \mathbb E[2(\phi z+1)z]=2\phi\,\mathbb E[z^2]+2\,\mathbb E[z]=2\phi. They agree.

Part 2. Not allowed. The mean of the sampling distribution is \phi. True side: \mathbb E[z]=\phi, gradient 1. Swapped side: z does not contain \phi, so \nabla_\phi z=0 and the average is 0. They disagree. Reparameterizing as z=\phi+\epsilon fixes it: \nabla_\phi(\phi+\epsilon)=1.

Part 3. Allowed. Picking a data point uniformly at random from a fixed training set is a distribution that does not depend on \phi. So the average loss is \mathbb E_n[\ell(x_n,\phi)] with n uniform, the gradient moves inside, and the mini-batch average of \nabla_\phi\ell(x_n,\phi) is an unbiased estimate. Problem 14: Why predict the log-variance?

Suppose we change the encoder so that its second output layer, a plain linear layer, returns \sigma directly instead of \log\sigma^2, and we compute \sigma^2 by squaring it.

  1. What range of values can a linear layer output, and which of those values are a problem for the KL term \frac12(\sigma^2+\mu^2-1-\log\sigma^2)?
  2. Explain how the log-variance parameterization avoids the problem without any constraint on the network.
TipWorked solution

This uses Week 7, VAE specifics and The encoder and decoder.

Part 1. A linear layer can output any real number, including 0 and negative numbers. At \sigma=0 we get \log\sigma^2=\log0=-\infty, so the KL is infinite, and near 0 the term -\log\sigma^2 and its gradient blow up. A negative \sigma is squared to the same variance as |\sigma|, so it is not wrong as a distribution, but the network has to pass through \sigma=0 to move between the two signs, and the loss is infinite there. Part 2. With the log-variance, the network outputs v=\log\sigma^2, which may be any real number. Then \sigma^2=e^v is automatically positive and never zero, \log\sigma^2=v is finite, and \sigma=e^{v/2} is smooth in v. No output value is invalid, so no constraint or special activation is needed. This is why fc_logvar has no activation.

Answer: a linear layer can output \sigma\le0, which makes \log\sigma^2 infinite or undefined; outputting \log\sigma^2 makes every real output valid.

(In floating point it can round to 1 for very large a, which is why PyTorch’s binary_cross_entropy clamps each log at -100 rather than returning infinity.)

Answer: terms 0.105, 0.223, 0.511, 0.010, total \approx0.849; pixel 3 dominates; p_2=1 would make the loss infinite.

Problem 23: Turning the β knob

The training loss is \ell=\mathrm{BCE}+\beta\cdot\mathrm{KL}. Predict what happens to (a) the reconstructions of training images and (b) images decoded from prior samples z\sim\mathcal N(0,I) in each case:

  1. \beta close to 0.
  2. \beta very large.
TipWorked solution

This uses Week 7, Tutorial question 8 and Sampling from the prior.

Part 1. \beta\to0. The loss is almost pure BCE, so the model behaves like a plain autoencoder. Nothing stops the encoder from shrinking \sigma toward 0 (sharper codes reconstruct better) or from placing codes far from the origin.

    1. Reconstructions are as sharp as the bottleneck allows.
    1. Prior samples are poor: the codes are no longer anchored to \mathcal N(0,I) and can have gaps (Problem 15), so many prior draws land where the decoder was never trained.

Part 2. \beta large. The KL dominates, and the cheapest way to make it small is q_\phi(z\mid x)\approx\mathcal N(0,I) for every image.

    1. Reconstructions degrade toward a blurry average image, because codes that look like the prior for every input carry little information about which input it was.
    1. Prior samples land where the decoder has been trained, so they decode to valid-looking (if bland) images more often.

The week chapter states the moderate version: increasing \beta above 1 packs codes closer to the prior, improving prior samples at the cost of lower-quality reconstructions. \beta=1 is the value at which the loss is exactly the negative ELBO.

Answer: small \beta: sharp reconstructions, poor prior samples; large \beta: blurry reconstructions, prior samples that more often decode to valid images.

Problem 24: Which term needs a sample?

  1. Explain why the KL term of the VAE loss can be computed exactly from the encoder’s outputs, while the reconstruction term needs a random sample.
  2. How many noise samples does the notebook’s training loop draw per image per gradient step, and what does it use instead of a sample in evaluation mode?
TipWorked solution

This uses Week 7, Tutorial question 7 and The full model and the reparameterization.

Part 1. Both distributions in the KL are Gaussians, q=\mathcal N(\mu,\mathrm{diag}(\sigma^2)) and p=\mathcal N(0,I), and the expectation of the log-ratio of two Gaussians has the closed form on the aid sheet. It is a formula in \mu and \log\sigma^2 alone, with no z left in it, so no sampling is needed. The reconstruction term is \mathbb E_{z\sim q}[\log p(x\mid z,\theta)], and \log p(x\mid z,\theta) depends on z through the decoder network f(z,\theta). There is no closed form for the expectation of a neural network’s output under a Gaussian, so it is estimated by Monte Carlo, and the reparameterization trick is what lets gradients reach the encoder through that sample.

Part 2. One. Each forward pass calls latent_sample once, which draws one \epsilon per image in the batch, so each image gets a single fresh noise sample per step: a one-sample Monte Carlo estimate. In evaluation mode (vae.eval()), latent_sample returns \mu instead of a sample, so the test loss decodes the mean code.

Answer: the KL is a closed-form function of \mu and \log\sigma^2; the reconstruction term passes z through a network and needs Monte Carlo. The notebook uses one sample per image per step, and z=\mu in evaluation mode.

Problem 26: A bug in latent_sample

A student’s version of latent_sample reads

def latent_sample(self, mu, logvar):
    if self.training:
        std = logvar.exp()
        eps = torch.empty_like(std).normal_()
        return eps.mul(std).add_(mu)
    else:
        return mu
  1. Compared with the notebook, what is different, and what quantity does std now hold? What distribution does the returned code actually have?
  2. The training loop still runs without error. Explain why, and why the loss being minimized is no longer the negative ELBO of the distribution being sampled.
  3. Does the bug change how the test loss is computed?
TipWorked solution

This uses Week 7, The full model and the reparameterization and The loss.

Part 1. The notebook has logvar.mul(0.5).exp_(), which is \exp(\tfrac12\log\sigma^2)=\sigma. The student’s line drops the \tfrac12, so std holds \exp(\log\sigma^2)=\sigma^2, the variance. The code is z=\mu+\sigma^2\epsilon, so z\sim\mathcal N(\mu,(\sigma^2)^2)=\mathcal N(\mu,\sigma^4). For example, an encoder output \log\sigma^2=-2 is meant to give standard deviation e^{-1}\approx0.368, but the sample uses e^{-2}\approx0.135.

Part 2. Every operation is still valid and differentiable: the shapes match, and gradients still flow through \mu and logvar. Nothing checks that the sampler and the KL formula describe the same distribution. But vae_loss still computes the KL as if the variance were e^{\text{logvar}}=\sigma^2, while the reconstruction term is evaluated at codes drawn with variance \sigma^4. The two terms now refer to different Gaussians, so their sum is not the negative ELBO of either one. Training still minimizes something, but not the objective the derivation justifies.

Part 3. No. In evaluation mode latent_sample returns \mu and never reaches the buggy line, so the test-loss computation is unchanged. The test number still differs, though, because the weights being evaluated were trained with the wrong sampler.

Answer: std holds \sigma^2, so z\sim\mathcal N(\mu,\sigma^4); the code runs, but the KL and the samples describe different distributions; evaluation mode is untouched because it uses z=\mu.

Problem 27: Averaging the BCE instead of summing (stretch)

A student changes one argument in vae_loss, leaving the KL line untouched:

recon_loss = F.binary_cross_entropy(recon_x.view(-1, 784), x.view(-1, 784), reduction='mean')

With a batch of B=64 images, reduction='mean' averages over all 784B pixel entries in the batch, while kldivergence is still summed over latent dimensions and images.

  1. Write the new loss as a constant times the notebook’s loss with a different \beta. What is the effective \beta?
  2. Using Problem 23, predict what the trained model’s reconstructions will look like.
TipWorked solution

This uses Week 7, The loss, including the notebook’s remark about averaging over pixels.

Part 1. Let S_\text{BCE} be the BCE summed over pixels and images (the notebook’s recon_loss) and S_\text{KL} the summed KL. The mean divides the sum by the number of entries, 784B=784\times64=50{,}176. So, with \beta=1, \ell_\text{new}=\frac{S_\text{BCE}}{50{,}176}+S_\text{KL}=\frac{1}{50{,}176}\Big(S_\text{BCE}+50{,}176\cdot S_\text{KL}\Big).

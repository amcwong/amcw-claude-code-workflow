Week 1

  • Supervised / unsupervised / semi-supervised / reinforcement learning: the four standard ML problem settings, distinguished by what data or signal is available during learning (week 1, What is machine learning).
  • Discriminative model: a model of the conditional p(c\mid x) only, used directly for prediction (week 1, Discriminative vs generative).
  • Generative model: a model of the joint p(c,x), which can also generate new examples (week 1, Discriminative vs generative).
  • Joint distribution: the probability of every combination of outcomes of two or more random variables (week 1, Joint, marginal, and conditional).
  • Marginal distribution: the distribution of one variable, obtained by summing the joint over the others (week 1, Joint, marginal, and conditional).
  • Conditional distribution: the distribution of one variable given a fixed value of another; joint divided by marginal (week 1, Joint, marginal, and conditional).
  • Sensitivity / specificity / prevalence: the true-positive rate, true-negative rate, and prior probability of a condition, the three numbers that define a diagnostic-test model (week 1, diagnostic test).
  • Parametric model: a family of distributions \{p(x\mid\theta):\theta\in\Theta\} indexed by a parameter (week 1, Parametric models).
  • i.i.d.: independently and identically distributed; each data point drawn independently from the same distribution (week 1, Parametric models).
  • Likelihood function: the probability of the observed data, viewed as a function of the parameter (week 1, Parametric models).
  • Log-likelihood: the logarithm of the likelihood; a sum instead of a product, easier to optimize (week 1, Parametric models).
  • Maximum likelihood estimation (MLE): choosing the parameter value that maximizes the likelihood of the observed data (week 1, MLE).
  • Sufficient statistic: a summary of the data that captures everything relevant to estimating the parameter; formalized by the Fisher–Neyman factorization theorem (week 1, Sufficient statistics).
  • Exponential family: the class of distributions expressible as h(x)\exp\{\eta^\top T(x) - A(\eta)\}, unifying the Bernoulli, Multinomial, Gaussian, and many other named distributions (week 1, Exponential families).
  • Natural parameter (\eta): the parameter coordinate an exponential family is written in terms of; not always the same coordinate as the distribution’s usual parameters (week 1, Exponential families and Gaussian).
  • Log-partition function (A(\eta)): the normalizing term of an exponential family; its derivative gives the mean of the sufficient statistic (week 1, Exponential families and mean of sufficient statistics).
  • Carrying measure / base measure (h(x)): the part of an exponential-family density that does not depend on the parameter (week 1, Exponential families).
  • Log-odds: \log\frac{\theta}{1-\theta} (or, for more than two outcomes, \log(q_i/q_K) against a reference class); the natural parameter of the Bernoulli and Multinomial exponential families (week 1, Bernoulli and Multinomial).

Week 2

  • Decision region (\mathcal{R}_k): a subset of the input space assigned to class \mathcal{C}_k; the decision regions partition the input space (week 2, From inference to decision).
  • Loss function / loss matrix (L_{kj}): the cost of deciding class j when the true class is k; generalizes plain misclassification rate, which is the special case of a 0/1 loss matrix (week 2, Expected loss).
  • Expected loss: the loss matrix weighted by the joint, integrated over the chosen decision regions; minimizing it over regions gives the discriminant rule (week 2, Expected loss).
  • Discriminant rule: assign x to the class j minimizing \sum_k L_{kj}\,p(\mathcal{C}_k\mid x) (week 2, The discriminant rule and the reject option).
  • Reject option: declining to decide when every class posterior falls below a threshold \theta (week 2, The discriminant rule and the reject option).
  • Regression function (y(x)): a function approximating a continuous target t from input x; under squared loss, the loss-minimizing choice is y(x)=\mathbb{E}[t\mid x] (week 2, Loss functions for regression).
  • Directed acyclic graphical model (DAG) / Bayes net: a graph whose nodes are random variables and whose edges encode assumed direct dependence, inducing the factorization p(x_i\mid\text{parents}(x_i)) (week 2, Directed graphical models).
  • Conditional probability table (CPT): the table of parameters for p(x_i\mid\text{parents}(x_i)) at one node of a DAG; a binary node with K_i parents needs 2^{K_i} parameters (week 2, Directed graphical models).
  • D-separation: the graph-theoretic criterion for reading conditional independence x_A\perp x_B\mid x_C directly off a DAG (week 2, Bayes Ball algorithm).
  • Causal chain / common cause / explaining away: the three canonical three-node independence structures; conditioning on the middle node blocks dependence in the first two, and conditioning on a common effect (or its descendant) can create dependence in the third (week 2, Conditional independence: three canonical structures).
  • Bayes Ball algorithm: an algorithm that tests x_A\perp x_B\mid x_C by “bouncing” a ball from nodes in A along the graph, blocked or passed at each node per the chain/common-cause/common-effect rules (week 2, The Bayes Ball algorithm).
  • Naive Bayes: a classifier whose graphical model assumes every feature is conditionally independent of every other feature given the class label, a common-cause structure with the class as the shared parent (week 2, Naive Bayes as a graphical model).
  • Hidden Markov model (HMM): a graphical model with a Markov chain of unobserved states, each emitting an observed variable at every time step (week 2, DGMs in the wild).
  • Noisy-OR: a conditional probability table shape in which a child node is likely positive if any one of its parents is positive, used in medical-diagnosis networks such as Quick Medical Reference (week 2, DGMs in the wild).

Week 3

  • Markov random field (MRF): an undirected graphical model where an edge means two variables interact directly, rather than one causing the other (week 3, Markov random fields, cliques, and the factorization theorem).
  • Clique / maximal clique: a subset of nodes all pairwise connected by an edge; maximal if it cannot be extended by one more adjacent node (week 3, Markov random fields, cliques, and the factorization theorem).
  • Potential function (\psi_C): a nonnegative, not-necessarily-normalized score attached to a clique’s joint variable setting; the product of potentials over all maximal cliques is proportional to the MRF’s distribution (week 3, Markov random fields, cliques, and the factorization theorem).
  • Partition function (Z): the normalizing constant that turns a product of potentials into an actual probability distribution (week 3, Markov random fields, cliques, and the factorization theorem).
  • Hammersley-Clifford theorem: for a strictly positive distribution, factorizing with respect to a graph G is equivalent to the global Markov property on G (week 3, The Hammersley-Clifford theorem).
  • Global Markov property: X_A\perp X_B\mid X_S whenever S separates A from B in the graph (week 3, The Hammersley-Clifford theorem).
  • Ising model: an MRF over spin variables x_s\in\{-1,+1\} with pairwise potentials \psi_{st}(x_s,x_t)=e^{J_{st}x_sx_t}, used to model magnets (week 3, The Ising model).
  • Precision matrix (K=\Sigma^{-1}): the inverse covariance matrix of a multivariate Gaussian; K_{ij}=0 if and only if X_i\perp X_j\mid X_{\text{rest}} (week 3, Gaussian graphical models).
  • Gaussian graphical model: an undirected graph on the coordinates of a multivariate Gaussian, with an edge between i,j exactly when K_{ij}\neq 0 (week 3, Gaussian graphical models).
  • Sample covariance matrix (S_n): the sufficient statistic \frac{1}{n}\sum_i \boldsymbol{x}_i\boldsymbol{x}_i^\top for maximum likelihood estimation of a (mean-zero) Gaussian’s covariance; the MLE is \hat\Sigma_{\text{MLE}}=S_n (week 3, Gaussian graphical models).
  • Evidence / query / remaining variables (x_E, x_F, x_R): the observed, to-be-inferred, and marginalized-out variables in an inference query p(x_F\mid x_E) (week 3, Exact inference as a conditional distribution).
  • Variable elimination: an exact inference algorithm that computes marginals or conditionals by summing out variables one at a time in a chosen order, reusing intermediate sums rather than enumerating the full joint (week 3, Variable elimination).
  • Elimination ordering: the order in which variables are summed out during variable elimination; it determines the algorithm’s computational cost, and finding the optimal order is NP-hard (week 3, Variable elimination).
  • Intermediate factor (\tau): a new, generally non-probabilistic function of the remaining variables produced by summing out one variable during variable elimination (week 3, Sum-product inference: unifying DAGMs and MRFs).
  • Sum-product algorithm: the general inference computation \tau(x_F,x_E)=\sum_{x_R}\prod_{C\in\mathcal{F}}\psi_C(x_C) shared by DAGs (factors = node plus parents) and MRFs (factors = maximal cliques) (week 3, Sum-product inference: unifying DAGMs and MRFs).
  • Restricted Boltzmann machine (RBM): a bipartite Ising model over visible and hidden binary units, with no within-layer edges, whose hidden units are conditionally independent given the visible units by Hammersley-Clifford (week 3, Restricted Boltzmann machines).

Week 4

  • Latent variable: an unobserved variable that governs some property of the observed data; it is either marginalized out or is itself the target of inference (week 4, Latent variables and the TrueSkill model).
  • TrueSkill model (course version): a player-ranking model with a latent skill z_i per player and p(i\text{ beats }j\mid z_i,z_j)=\sigma(z_i-z_j) for the standard logistic function \sigma (week 4, Latent variables and the TrueSkill model).
  • Tree: a connected undirected graph with no cycles; a leaf is a node with exactly one neighbour (week 4, Trees and elimination order).
  • Message (m_{j\to i}(x_i)): the summary node j sends neighbour i, \sum_{x_j}\psi_j(x_j)\psi_{ij}(x_i,x_j)\prod_{k\in N(j)\setminus\{i\}}m_{k\to j}(x_j), with one entry per state of x_i; on a tree it equals an intermediate factor of variable elimination (week 4, Messages and beliefs).
  • Belief (b(x_i)): the normalized product \psi_i(x_i)\prod_{j\in N(i)}m_{j\to i}(x_i); on a tree it is the exact marginal of x_i given the evidence (week 4, Messages and beliefs).
  • Belief propagation (BP) / sum-product BP: message passing that computes every node marginal of a tree in two passes, leaves to root and root to leaves (week 4, Belief propagation on trees).
  • Loopy belief propagation: BP updates iterated from uniform messages on a graph with cycles; gives approximate, often over-confident marginals without a general convergence guarantee (week 4, Loopy belief propagation).
  • Momentum (in loopy BP): updating a message as (1-\alpha)m^{\text{old}}+\alpha\,[\text{update}] with step size \alpha, to damp oscillation (week 4, Loopy belief propagation).
  • Maximum a posteriori (MAP) estimate: the most probable value of the unobserved variables given the evidence, \arg\max_{x_F}p(x_F\mid x_E) (week 4, Max-product BP and MAP inference).
  • Max-product BP / max-marginal: BP with each message’s sum replaced by a max; the resulting beliefs are max-marginals, and \hat x_i=\arg\max_{x_i}b(x_i) gives the MAP estimate (week 4, Max-product BP and MAP inference).
  • Sample: a single realization x whose distribution is p(x) (week 4, Sampling from an unnormalized density).
  • Topological order: an ordering of a DAG’s nodes in which every node comes after all its parents (week 4, Ancestral sampling).
  • Ancestral sampling: sampling a DAG’s joint by drawing each node from p(x_i\mid\text{parents}(x_i)) in topological order (week 4, Ancestral sampling).
  • Test function (\phi): the function whose expectation \Phi=\mathbb{E}_{x\sim p}[\phi(x)] a Monte Carlo method estimates (week 4, What sampling is for).
  • Simple Monte Carlo estimator (\hat\Phi): the sample average \frac1R\sum_r\phi(x^{(r)}) over draws from p; unbiased, consistent, with variance \mathrm{var}[\phi]/R (week 4, Simple Monte Carlo).
  • Unbiased / consistent estimator: an estimator whose expected value equals the target, and one that converges to the target as the sample size grows (week 4, Simple Monte Carlo).
  • Importance sampling: estimating \mathbb{E}_p[\phi] from samples of a proposal q, weighting each by \tilde w_r=\tilde p(x^{(r)})/\tilde q(x^{(r)}) and normalizing the weights (week 4, Importance sampling).
  • Proposal density (q): an easy-to-sample, easy-to-evaluate distribution used in place of the target p by importance and rejection sampling (week 4, Importance sampling).
  • Rejection sampling: drawing exact samples from p by proposing x\sim q, drawing u uniform on [0,c\tilde q(x)], and accepting when u\le\tilde p(x); the acceptance rate is Z_p/(cZ_q) (week 4, Rejection sampling).

Week 5

  • Markov chain (first-order): a sequence with p(x_t\mid x_{1:t-1})=p(x_t\mid x_{t-1}); an m-th order chain conditions on the previous m values instead (week 5, Markov chains; first previewed in week 2).
  • Stationary (homogeneous) Markov chain: a chain whose transition probabilities do not change with t. Not the same as a stationary distribution (week 5, Markov chains).
  • Transition matrix (A): the K\times K matrix A_{ij}=p(x_t=j\mid x_{t-1}=i) of a discrete stationary chain; each row sums to 1 (week 5, Transition matrices).
  • State transition diagram: a directed graph with one node per state value and an arrow i\to j labelled A_{ij} for each nonzero transition (week 5, Transition matrices).
  • n-step transition matrix / Chapman-Kolmogorov equations: A_{ij}(n)=p(x_{t+n}=j\mid x_t=i), with A(m+n)=A(m)A(n) and so A(n)=A^n (week 5, n-step transitions).
  • Markov (bigram) language model: a Markov chain over words with start probabilities \pi_j and transitions A_{jk}, fitted by \hat A_{jk}=N_{jk}/\sum_{k'}N_{jk'} (week 5, Markov language models).
  • Stationary distribution: a distribution \pi over states with \pi=A^\top\pi, found as a normalized eigenvector of A^\top with eigenvalue 1; also called invariant (week 5, The stationary distribution).
  • Irreducible / regular chain: irreducible if every state can reach every other; regular if some A^n is entrywise positive. A regular finite chain has a unique stationary distribution and converges to it from any start (week 5, When is the stationary distribution unique?).
  • Detailed balance / time reversible: \pi_iA_{ij}=\pi_jA_{ji} for all i,j; it implies \pi is stationary (week 5, Detailed balance).
  • Markov chain Monte Carlo (MCMC): sampling by running a Markov chain whose stationary distribution is the target p, then averaging over its (dependent) states (week 5, Why MCMC).
  • Proposal density, MCMC sense (q(x'\mid x)): a conditional distribution that proposes the next state from the current one. A stricter sense of week 4’s fixed proposal q(x) (week 5, Why MCMC).
  • Burn-in: the initial stretch of an MCMC chain that is discarded because the chain has not yet reached its stationary distribution (week 5, Why MCMC).
  • Metropolis-Hastings (MH): propose x'\sim q(x'\mid x) and accept with probability \min\{1,\ \tilde p(x')q(x\mid x')/(\tilde p(x)q(x'\mid x))\}, otherwise repeat the current state; the Metropolis algorithm is the symmetric-proposal case (week 5, The Metropolis-Hastings algorithm).
  • Acceptance probability (\alpha(x'\mid x)): the probability that an MCMC step moves to the proposed state; not the \alpha of the two-state chain (week 5, The Metropolis-Hastings algorithm).
  • Beta distribution: the distribution on (0,1) with density \propto\theta^{a-1}(1-\theta)^{b-1}; \mathrm{Beta}(1,1) is uniform, and a Beta prior with a Binomial likelihood gives a Beta posterior (conjugacy) (week 5, Clemente’s batting average).
  • Gibbs sampling: MCMC that resamples one coordinate at a time from its full conditional, accepting every draw; a special case of MH (week 5, Gibbs sampling).
  • Full conditional: p(x_j\mid x_{-j}), the distribution of one coordinate given all the others (week 5, Gibbs sampling).
  • Energy (E(x)): -\log\tilde p(x), so that p(x)\propto e^{-E(x)}; low energy means high probability. Not an expectation \mathbb{E} (week 5, Hamiltonian Monte Carlo).
  • Momentum, HMC sense (v): an auxiliary Gaussian variable with kinetic energy \tfrac12\|v\|^2. Unrelated to the damping momentum of loopy BP in week 4 (week 5, Hamiltonian Monte Carlo).
  • Hamiltonian (H(x,v)): total energy E(x)+K(v); exact Hamiltonian dynamics conserve it (week 5, Hamiltonian Monte Carlo).
  • Leapfrog integrator: a numerical scheme for Hamiltonian dynamics: a half step in momentum, a full step in position, a half step in momentum; deterministic and reversible (week 5, The leapfrog integrator).
  • Hamiltonian Monte Carlo (HMC): MH whose proposal draws v\sim\mathcal N(0,I), runs L leapfrog steps, and flips the momentum; accepted with probability \min\{1,e^{H_{\text{start}}-H_{\text{end}}}\} (week 5, The leapfrog integrator and the HMC algorithm).
  • Mixing: an MCMC chain mixes well when it has reached and moves freely around its target distribution (week 5, MCMC diagnostics).
  • Autocorrelation (\rho_t): the correlation between a chain’s draws t steps apart (week 5, Effective sample size).
  • \hat R (R-hat) / split-\hat R: \sqrt{\widehat{\mathrm{var}}^+/W}, comparing between-chain and within-chain variance; near 1 when chains agree, above 1 when they have not mixed. Split-\hat R also splits each chain in half (week 5, The R-hat statistic).
  • Effective sample size (n_{\text{eff}}): mn/(1+2\sum_{t\ge1}\rho_t), the number of independent draws that would give the same accuracy as m correlated chains of length n (week 5, Effective sample size).
